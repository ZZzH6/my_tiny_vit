# 轻量化 Transformer 图像分类毕设工作量分析

目前的 `train_lite_vit.py` 代码为你提供了一个非常扎实、现代化的基线（Baseline），但如果直接把它作为本科甚至硕士毕业设计，在“工作量”和“创新性”上可能显得单薄。

毕设的评审老师通常看重以下几点：
1. **你是不是只调了个包（API）？**
2. **你有没有进行充分的对比实验？**
3. **你是否对模型结构或部署环节进行了针对性改进？**

为了让你的毕设显得非常有“工作量”且容易拿高分，你可以从以下几个维度去扩充和包装你的工作：

## 1. 核心工作量体现：多模型横向对比实验 (Ablation & Comparative Study)
目前代码只训练了一个 `mobilevit_xxs`。你需要横向对比不同的轻量化架构，证明你的选择是相对优秀的。
- **引入更多 Baseline**：修改代码，支持通过命令行参数（argparse）切换模型，如：
  - 传统轻量化 CNN：`MobileNetV3`, `ShuffleNetV2`
  - 其他轻量化 ViT：`MobileViT_S`, `GhostNetV2`, `EdgeNeXt`
- **对比指标**：在测试集上不仅要对比**准确率 (Accuracy)**，还要编写代码统计**参数量 (Params)**、**计算量 (FLOPs)** 和**推理延迟 (Latency / FPS)**。
- *在论文中可以花大量篇幅列出表格和绘制柱状图，这是极好的工作量体现。*

## 2. 核心工作量体现：改进模型架构 (Architecture Modification)
这是毕设最容易出彩（“水”字数和创新点）的地方。不要只用原生的 `timm` 模型。
- **引入注意力机制模块**：在 MobileViT 的深层或浅层特征图之后，手动插入即插即用的注意力模块（如 `CBAM`, `SE-Net`, `Coordinate Attention`）。
- **修改分类头**：将最后的单层 Linear 替换为带有 Dropout 或多层感知机（MLP）的定制分类头，提升鲁棒性。
- *在论文中可以画架构改进前后的对比图，指出你的“改进点”，哪怕准确率只提升了 0.5%，在毕设层面也是非常成功的。*

## 3. 核心工作量体现：训练策略的高级优化 (Training Strategy Optimization)
你目前已经使用了 `AutoAugment`, `Label Smoothing`, `OneCycleLR` 和 `AMP`，这些在论文里都是极好的“凑字数”和体现专业性的点。你需要把它们作为你的“训练策略实验”：
- **消融实验 (Ablation Study)**：跑几个对比实验，分别是：
  1. 基础瞎跑（不加任何优化策略）
  2. 加了高级数据增强（AutoAugment / Mixup / CutMix）
  3. 加了 Label Smoothing + OneCycleLR
- *然后在论文里画出 Loss 下降的对比曲线图，证明你设计的训练策略确实让模型收敛得更好。*

## 4. 核心工作量体现：模型量化与边缘端部署探讨 (Quantization & Deployment)
既然题目是“轻量化”，如果只停留在训练出高精度模型是不够的，还需要证明它能在算力受限的设备上跑。
- **添加量化脚本 (INT8 Quantization)**：使用 PyTorch 自带的 `torch.quantization` (PTQ 训练后量化) 脚本，把 float32 的模型转换为 int8，测试体积缩小了多少（通常是 1/4），精度下降了多少（通常下降不到 1%）。
- **导出推理格式**：编写脚本将模型导出为 `ONNX` 或 `TensorRT` 格式，比较推理速度的提升。
- *在论文的最后几章，这部分内容极其讨喜，能体现你具备工程落地能力。*

## 总结：你的毕设还需要写什么代码？
为了让工作量“爆满”，你可以补充以下外围脚本：
1. 一个独立的**推理与评估脚本 (`eval.py`)**，用于计算 FPS、FLOPs 和混淆矩阵。
2. 一个允许**轻松修改模型结构的文件 (`models.py`)**，加入你自己的“改进版 MobileViT”。
3. 扩展当前的训练代码，支持**各种消融实验参数配置**（使用 `argparse`）。
4. 一个简单的 **模型量化与导出脚本 (`export.py`)**。

只要把这四个点补齐，搭配目前代码中已经用到的这些高级训练技巧（例如 `OneCycleLR`、`AutoAugment`、`AMP混合精度`），你的代码工作量和论文可写内容对于一个优秀的图像分类毕设来说就非常充足甚至溢出了！
